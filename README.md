# Inventory Management CLI

A command-line inventory management system.

## Features

**Inventory Management**
- Add items
- Remove items
- View inventory
- View item details
- Search inventory
- Track item weight
- Enforce maximum carry weight
- Display remaining inventory capacity

**Equipment**
- Equip weapons, armor, shields
- View equipped equipment
- Unequip items

**Player**
- Add / remove gold
- View player statistics

**Shop**
- Buy / sell items

**Loot**
- Random loot generation
- Loot chests

**Durability**
- Track item durability
- Track maximum durability
- Repair damaged items

**Save / Load**
- Save game state
- Load saved state

## Getting Started

**1. Clone the repository:**
```bash
git clone https://github.com/<your-username>/inventory-management-cli.git
```
**2. Navigate into the project folder:**
```bash
cd inventory-management-cli
```
**3. Install dependencies:**
```bash
npm install
```
**4. Start app:**  
```bash
node src/index.js
```
